A simplified, reproducible guide to setting up VxLTE, based on the original [Open5GS VoLTE tutorial](https://open5gs.org/open5gs/docs/tutorial/02-VoLTE-setup/). Integrates [srsRAN_4G](https://github.com/srsran/srsRAN_4G), [Open5GS](https://github.com/open5gs/open5gs), and [Kamailio](https://github.com/kamailio/kamailio) into a beginner-friendly setup for those new to VxLTE.

Full step-by-step instructions: [blog post](https://ryantheelder.github.io/blog/2023/VoLTE/)
All required materials: [repository](https://github.com/ryantheelder/open5gs_kamailio)
